# Настройка Gemini как командного интерфейса

## Вариант 1: Gemini Gem (рекомендуется)

Gemini Gems — это кастомные агенты в мобильном приложении Gemini.
Открой: Gemini App → Explore → My Gems → Create

**Название Gem:** AI CEO Commander

**Системная инструкция для Gem:**
```
Ты — командный интерфейс для системы AI CEO Orchestrator.

Когда пользователь пишет любую команду или вопрос о бизнесе,
ты должен отправить POST запрос на:
https://ВАШ-ДОМЕН.vercel.app/api/command

Тело запроса:
{
  "command": "<оригинальный текст пользователя>",
  "secret": "ВАШ_WEBHOOK_SECRET"
}

После получения ответа — покажи пользователю поле "reply" из JSON ответа.

Примеры команд которые пользователь может говорить/писать:
- "утренний брифинг" — сводка оперативных отделов
- "как дела с продажами?" — анализ отдела продаж
- "полный анализ" — все 7 отделов (занимает 3-5 минут)
- "статус" — последние запуски системы
- "бриф: продукт=Химчистка авто, цель=100 клиентов" — обновить бриф

Ты не придумываешь ответы сам — ты всегда делаешь запрос к системе
и показываешь её ответ.
```

## Вариант 2: Напрямую через Gemini + Google Apps Script

Если Gems недоступны, используй Google Apps Script как прослойку:

1. Создай Google Sheet
2. В меню → Extensions → Apps Script:

```javascript
function sendToOrchestrator(command) {
  const url = 'https://ВАШ-ДОМЕН.vercel.app/api/command'
  const payload = {
    command: command,
    secret: 'ВАШ_WEBHOOK_SECRET'
  }
  
  const response = UrlFetchApp.fetch(url, {
    method: 'post',
    contentType: 'application/json',
    payload: JSON.stringify(payload)
  })
  
  const result = JSON.parse(response.getContentText())
  return result.reply
}

// Триггер: запускай из Sheet кнопкой или по расписанию
function dailyBriefing() {
  const result = sendToOrchestrator('утренний брифинг')
  // Можно записать в Sheet или отправить email
  GmailApp.sendEmail('ВАШ@EMAIL.COM', 'AI CEO Briefing', result)
}
```

## Вариант 3: Голосовой ввод через Gemini Live

Gemini Live (голосовой режим) → говоришь команду → 
Gemini транскрибирует → Gem отправляет запрос.

Работает особенно хорошо для:
- "Запусти маркетинговый анализ"
- "Что с продажами за эту неделю?"
- "Обнови бриф: новая цель — 200 клиентов"

---

## Практические советы по использованию

### Утро (2 минуты)
Голосом в Gemini: *"Утренний брифинг"*
→ получаешь топ-3 действия на день в Telegram

### В течение дня
*"Как дела с продажами?"* — быстрый анализ одного отдела (~30 сек)
*"Что делает маркетинг?"* — план контента и объявления

### Еженедельно (автоматически в пятницу)
Vercel Cron сам запускает полный анализ и присылает в Telegram

### Когда что-то изменилось
*"Бриф: цель=500 клиентов, бюджет=100000"*
→ обновляет бриф, следующие запуски учтут новые данные
